# Configs Directory

Training YAML configuration files are auto-generated by the `generate_training_yaml()` function during training.

## Generation

Running `train_all.py` automatically generates YAML configurations for each model:

```
configs/
├── internvl3_8b.yaml
├── llava_onevision_7b.yaml
├── qwen2_5_vl_7b.yaml
└── gemma3_4b.yaml
```

## Manual Editing

To adjust hyperparameters (learning rate, batch size, epochs), edit the corresponding YAML directly, then run:

```bash
conda activate vlm_defect
llamafactory-cli train configs/internvl3_8b.yaml
```

## Key Parameters

| Parameter | Value | Description |
|---|---|---|
| `finetuning_type` | lora | LoRA fine-tuning |
| `lora_rank` | 16 | LoRA rank |
| `lora_alpha` | 32 | LoRA alpha |
| `quantization_bit` | 4 | 4-bit NF4 quantization |
| `per_device_train_batch_size` | 1 | Batch size (with gradient accumulation 8) |
| `gradient_accumulation_steps` | 8 | Simulates batch_size=8 |
| `learning_rate` | 0.0001 | Cosine schedule with warmup |
| `num_train_epochs` | 3 | Training epochs |
| `bf16` | true | BFloat16 mixed precision |
| `gradient_checkpointing` | true | Memory optimization |
